BlockFire Launcher

Безкоштовний лаунчер Minecraft зі збірками, модами Forge, Fabric і Quilt, автозавантаженням Java та оновленнями прямо в програмі.

Завантажити для Windows Telegram-канал

Якщо Windows покаже попередження про невідомого видавця, натисни «Докладніше», потім «Все одно запустити». Це нормально для програм без платного підпису.

Що вміє лаунчер

ЗбіркиОбираєш версію й завантажувач, даєш назву, і збірка зʼявляється на головному екрані зі своєю папкою модів.
Усі версіїСписок версій береться з серверів Mojang. Старі версії та снапшоти вмикаються в налаштуваннях.
МодиForge, Fabric і Quilt. Кнопка «Додати мод» кладе .jar у потрібну папку збірки.
Java без клопотуЛаунчер сам завантажує потрібну Java під кожну версію гри й оновлює її.
Оновлення в програміВийшла нова версія лаунчера, і він сам запропонує оновитись, показавши, що нового.
Свій стильТеми Vista, 7, 10 і 11, заставки з Minecraft, 4 мови, пароль на вхід і список друзів.
